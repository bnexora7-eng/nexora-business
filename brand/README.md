# ALPINOSS brand assets

These are the repository's preserved brand reference assets for the ALPINOSS identity.

- `../alpinoss-brand.svg` — approved primary logo artwork. Keep the artwork, proportions, colours and composition unchanged.
- `../alpinoss-icon.svg` — matching compact app icon.
- `alpinoss-background.css` — reusable reference for the dark navy / electric-blue background treatment, grid texture and red-blue atmospheric lighting.

Do not replace the logo with a newly generated interpretation or redesign the background independently. Any future export or format conversion must preserve the approved original appearance. Use the same brand palette across the website, account pages, profile artwork and app surfaces.
